# InnovGen 3D Website Blueprint

This package defines the scalable frontend-first redesign of InnovGen's website using Next.js, TypeScript, Tailwind CSS, Motion for React, React Three Fiber, Three.js, Drei, Lenis, and other free/open-source tooling.

## Phase 1 Scope
- Complete frontend website
- Responsive desktop, tablet, and mobile layouts
- 3D hero scenes and interactive visual sections
- Smooth scrolling and scroll-linked animation
- Accessible reduced-motion mode
- CMS-ready data architecture
- Mock/API-ready content models
- SEO-ready structure
- Performance budgets and testing requirements
- Backend integration contracts prepared but not implemented

## Recommended Backend for Phase 2
- Supabase for Postgres, authentication, storage, realtime, and edge functions
- NestJS service layer only when business logic becomes complex, integrations grow, or multiple apps must share APIs
- PostgreSQL as the long-term source of truth
