# 08 — Development Roadmap

## Phase 0 — Discovery
| Deliverable | Acceptance |
|---|---|
| Content inventory | Existing pages and assets mapped |
| Brand confirmation | Logo, palette, type, tone approved |
| Technical audit | Existing domain, analytics, SEO, hosting reviewed |
| 3D feasibility | Target devices and performance class agreed |
| Content gaps | Missing products, projects, metrics, certifications identified |

## Phase 1 — Frontend Foundation
| Sprint | Scope |
|---:|---|
| 1 | Repository, Next.js, TypeScript, Tailwind, linting, testing, CI |
| 2 | Design tokens, typography, layout, header, footer, buttons |
| 3 | Global canvas, reduced-motion system, asset loader, performance monitor |
| 4 | Home page sections and hero scene |
| 5 | About and Services pages |
| 6 | Products and Projects indexes/details |
| 7 | Partners, Blogs, Careers |
| 8 | Consultation forms with mocked submission |
| 9 | Responsive refinement and accessibility |
| 10 | Performance optimization, SEO, testing, deployment |

## Phase 1 Definition of Done
| Area | Requirement |
|---|---|
| Pages | All agreed routes complete |
| Responsive | 320px through wide desktop |
| 3D | Full desktop, optimized tablet/mobile, static fallback |
| Motion | Smooth and reduced-motion compliant |
| Content | Real approved content or clearly marked placeholders |
| Forms | Validated frontend flows and API-ready payloads |
| SEO | Metadata, schemas, sitemap, robots |
| QA | Browser, accessibility, performance tests |
| Handover | README, environment example, component docs |

## Phase 2 — Backend and CMS
| Workstream | Scope |
|---|---|
| Supabase | Database, auth, storage, RLS |
| Content | CMS/admin workflow |
| Forms | Real submissions, notifications, spam protection |
| Careers | Applications and file uploads |
| Blog | Editorial publishing |
| Analytics | Events and conversion measurement |
| Integrations | CRM, email, calendar as selected |

## Phase 3 — Growth
| Workstream | Scope |
|---|---|
| Personalization | Industry or campaign landing pages |
| Client portal | Secure project/client area |
| Advanced search | Cross-site search |
| Automation | CRM workflows and lead scoring |
| Optimization | A/B testing and content experiments |
