# 05 — Content and SEO Strategy

## Core Messaging
| Element | Direction |
|---|---|
| Positioning | Enterprise technology partner delivering secure, scalable digital systems |
| Hero promise | Clear business outcome before technical detail |
| Tone | Confident, concise, evidence-led |
| Proof | Verified projects, partners, certifications, metrics |
| CTA hierarchy | Get Free Consultation → View Projects → Explore Services |

## SEO Requirements
| Area | Requirement |
|---|---|
| Metadata | Unique title and description per route |
| Schema | Organization, Service, Product, Article, JobPosting, BreadcrumbList |
| URLs | Short, descriptive, lowercase slugs |
| Headings | One meaningful H1 per page |
| Internal links | Services ↔ projects ↔ blogs ↔ products |
| Images | Descriptive filenames, alt text, responsive sizing |
| Canonicals | Required for indexable pages |
| Sitemap | Dynamic XML sitemap |
| Robots | Environment-aware robots.txt |
| Open Graph | Branded image and metadata |
| Performance | 3D must not prevent HTML indexing |
| Blog | Author, date, updated date, reading time, categories |
| Localization | Future hreflang readiness for English/Arabic |

## Content Models
| Model | Key Fields |
|---|---|
| Service | title, slug, summary, capabilities, benefits, process, technologies, FAQs, related projects |
| Product | title, slug, summary, features, gallery, integrations, deployment, FAQs |
| Project | title, slug, client/sector, challenge, solution, results, technologies, testimonial |
| Blog | title, slug, excerpt, body, author, category, tags, dates, SEO |
| Career | title, slug, department, location, type, description, requirements, status |
| Partner | name, category, logo, description, link, priority |
| Global Setting | navigation, footer, contact, social, default SEO |

## Content Governance
| Rule | Requirement |
|---|---|
| Claims | No unverified awards, partners, certifications, or statistics |
| Case studies | Obtain client approval |
| Updates | Assign owner and review date |
| Blog workflow | Draft → technical review → brand review → publish |
| Accessibility | Avoid text embedded only inside images |
| Localization | Keep content fields translation-ready |
