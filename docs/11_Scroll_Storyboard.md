# 11 — Scroll Storyboard

## Purpose

This document defines how each major website section should tell a clear business story through scrolling, motion, interaction, and 3D visuals.

The objective is not to animate everything. The objective is to guide the visitor from understanding InnovGen, to trusting InnovGen, to taking action.

---

# Global Storytelling Rules

| Rule | Requirement |
|---|---|
| Story first | Every animation must communicate a business idea |
| One idea per section | Avoid showing too many concepts at once |
| HTML content first | Text, CTAs, and important information remain outside WebGL |
| Progressive intensity | Begin calm, increase depth, then settle before CTA |
| Smooth transitions | Each section should visually lead into the next |
| Reduced motion | Every animated section must have a simplified alternative |
| Mobile adaptation | Replace heavy 3D with simplified motion or poster fallback |
| Performance | Pause offscreen scenes and reduce rendering quality when necessary |
| Accessibility | Scrolling must remain native and keyboard-friendly |
| Conversion | Each page must lead toward one primary action |

# Global Page Transition Storyboard

| Transition | Behavior |
|---|---|
| Link click | Immediate route navigation; do not delay unnecessarily |
| Page exit | Very short opacity transition only |
| Page entry | Header remains stable; content reveals progressively |
| Scroll restoration | Preserve browser behavior |
| Loading | Show lightweight branded loading state only when needed |
| Error | Display useful error message and recovery action |
| Reduced motion | Remove page movement and use direct rendering |

# Mobile Storytelling Adaptation

| Desktop Experience | Mobile Alternative |
|---|---|
| Pinned 3D scene | Shorter non-pinned section |
| Pointer parallax | Removed |
| Large particle field | Reduced particle count or static background |
| Horizontal scroll corridor | Swipeable cards or vertical stack |
| Camera movement | Gentle object movement |
| Multiple interface planes | One focused interface at a time |
| Complex transformations | Fade and scale transitions |
| Continuous animation | Event-based or paused animation |
